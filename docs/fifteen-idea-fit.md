# Fit of the fifteen engineering ideas

This is a capability ledger, not a claim that fifteen separate projects were
implemented. Existing components predate this redevelopment unless stated.

| Idea | XploreMore decision and evidence |
|---|---|
| 1. Dynamic Context Assembler | Partial adjacent behavior only: short MCP excerpts and bounded evidence exports. No token-budget middleware. |
| 2. Durable State Machine Workflow | Applied the recovery principle to the existing transactional indexer. New real-process commit/ack/replay tests prove the stated local boundaries. No Temporal/LangGraph workflow or Slack approval integration. |
| 3. Raw MCP Server & Client | Existing scoped REST-backed MCP server remains useful. It uses the MCP library, so it is not a from-scratch wire-protocol implementation. |
| 4. System-One Triage Router | Not added: there is no paid inference serving loop to route. No 95/5 claim. |
| 5. Self-Correcting Agentic RAG | Existing evaluated hybrid retrieval retained. No autonomous query rewriting or generated-answer critic claimed. Recorded title search is explicitly keyword-based. |
| 6. Three-Tier Memory Engine | Not added: immutable capture and local topic follows solve the current task without agent memory. |
| 7. Trajectory CI Gate | Adapted executable recovery boundaries and evidence receipts. Existing retrieval/brief contracts remain. This is not a golden agent tool-call trajectory grader. |
| 8. Inter-Agent Sanitization Proxy | Evidence stays untrusted and separate from human approval in the existing Pro2Pro handoff. No inter-agent security proxy is implemented here. |
| 9. Real-Time Voice Interruption | Not relevant to evidence discovery; not added. |
| 10. DPO Feedback Flywheel | No reviewed preference dataset or justified fine-tuning task; not added. |
| 11. Cost Kill-Switch & Degradation | The new explicit recorded edition needs no model/database hosting. Connected lexical mode already exists. This is a declared operating mode, not a metered multi-provider kill-switch or silent fallback. |
| 12. Shadow Routing Comparator | Historical paired offline search experiments are reproduced separately. They are not live shadow routing. |
| 13. Computer-Use Fallback | Not added: polling uses public feeds/APIs; browser QA is testing, not a product agent capability. |
| 14. PII Unmasking Proxy | Public exporter omits author hashes and internal text. Existing source ingestion pseudonymizes authors. No reversible token vault or unmasking gateway is claimed. |
| 15. Public Architecture Teardown | Local case study documents a reproduced accounting defect, alternatives, process recovery and limits. It becomes public only after approved publication. |

The strongest profile evidence is a reproducible engineering decision: a real
failure, a bounded correction, tests that would catch regression, and an honest
product demonstration. Adding unrelated frameworks would not establish those
outcomes. See [release evidence](reports/trusted-discovery-v1.md).
