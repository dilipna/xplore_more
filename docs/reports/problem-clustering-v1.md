## Known issues (v1)

1. **Maintainer roadmaps and tracking issues are admitted and merge with each other.** The labeling guidelines never addressed them, so the classifier learned them as `missing_capability` / `cost_or_performance`. v2 guidelines should decide whether planning issues are demand evidence.
2. **Same-thread opinion comments** about one article can merge because their topic is identical.
3. **Single-platform demand.** No problem in this snapshot spans two platforms, so `source_count` rarely exceeds 1 and demand is driven by voices and engagement.
4. **Version conflicts are decisive** (logit -10): one bug reported against two versions stays split.
5. **Every GitHub issue is admitted.** The classifier's platform feature dominates for GitHub (96% of labeled GitHub items are problems), so admission there is effectively unconditional.
